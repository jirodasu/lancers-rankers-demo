# GAME EDITOR — 8人のランカー実戦プレビュー

## すぐ遊ぶ

1. [GAME EDITOR](./) を開き、「敵を作る」モードへ進む。
2. 左の「作成中のランカー」からRank 8〜1を選ぶ。
3. 「この敵と戦う」を押す。新しいタブで独立した[実戦プレビュー](./arena.html)が開く。
4. 「戦闘開始」を押す。赤い攻撃予告を避け、敵に近づいて攻撃する。

PC: WASD／矢印で移動、Jで攻撃、Kで回避。スマホ: フィールド左側をドラッグして移動、右下の攻撃・回避ボタンを使う。

## 数値の変更

Factoryで下書きのHP、技の種類、予告時間、攻撃時間、ダメージを編集する。変更は同じブラウザのローカル保存領域に自動保存される。実戦プレビューを再読み込みすると、保存した設定が反映される。別ブラウザ・別端末への同期はしない。

## この版でできること

- Rank 8〜1の8体を選んで実際に戦う
- 6種類の共通攻撃形状（突き、突進、薙ぎ払い、飛び道具、旋回、連撃）
- 予告、当たり判定、ダメージ、回避、撃破、タイム評価
- 8体それぞれの仮の移動傾向、技名、数値を比較する

## 未実装

- 既存のPyxel本編へのRank 8〜1の組み込み
- キャラクターごとの専用アニメーション・画像・音
- 神話固有技の複雑な仕組み（クーフェリンの二段階予告など）
- AIによる自動実戦プレイテストと難易度の最終調整

この実戦プレビューは**ゲーム本編とは別の試作戦闘**であり、Rank 9・10の既存ゲーム動作を変更しない。キャラクター名（Rank 8〜2）と性能値は仮案。
